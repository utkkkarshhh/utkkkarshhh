Project Abstract & Scope

{% if project.slug == 'decentralized-election' %} This major project report explores the formulation and practical implementation of an immutable electoral protocol leveraging the Ethereum blockchain virtual machine (EVM). Traditional centralized electronic and manual ballot counting schemes suffer from single points of failure, vulnerable backends, and opaque auditing pipelines. By framing the electoral registry and ballot tallying process as a deterministic state machine governed by Solidity smart contracts, the system guarantees that only authorized public keys can cast a single ballot, while making every stage of the election tally cryptographically auditable in real time. The report analyzes contract gas optimization, Sybil resistance, and the security boundaries of decentralized governance applications. {% elif project.slug == 'multithreaded-scheduler' %} This major project report investigates concurrency bottlenecks, worker thread starvation, and priority-preemptive task scheduling in compute-intensive and I/O-bound application runtimes. As concurrent workloads grow, unmanaged thread spawning causes severe context-switching overhead and CPU cache thrashing. The project implements a robust priority queue mechanism with dynamic worker pooling in Java, complemented by an asynchronous FastAPI and Redis task dispatching architecture. A WebSocket monitoring pipeline provides real-time visualization of queue depth, worker saturation, and latency metrics under varying load conditions, demonstrating a 35% improvement in task throughput compared to naive sequential queues. {% else %} {{ project.problem }} {% endif %}
